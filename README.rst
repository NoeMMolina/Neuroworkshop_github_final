Neuroworkshop: TIS, Sleep and Memory Consolidation
=================================================

These notebooks accompany the Neuroworkshop on **temporal interference
stimulation (TIS) during sleep**, exploring its potential to enhance memory
consolidation.

The hands-on sessions introduce sleep-stage classification with **YASA and
GSSC**, sleep spindle detection, and slow-wave and slow-oscillation analysis.
Together, these workflows support the study of EEG markers relevant to sleep,
memory consolidation and the timing of stimulation.

Open the numbered notebooks in VS Code and follow their setup instructions.
Use ``requirements-yasa.txt`` for notebooks 01–03 and
``requirements-gssc.txt`` for notebook 04.
